# Bento Dashboard

A React dashboard UI project with multi-view navigation and local state persistence.

## Features

- Dashboard, analytics, wallet, settings, and admin views
- Transaction list and add-transaction modal
- Theme toggle
- Recharts activity visualization
- Local storage persistence for demo state

## Run

```bash
cd frontend/bento-dashboard
npm install
npm run dev
```

## Tech

- React
- Vite
- Recharts
- lucide-react
