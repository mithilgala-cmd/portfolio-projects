# Code Review AI Frontend

React + Monaco frontend for the Code Review AI backend.

## Features

- Monaco editor with language selection
- Sample starter code for quick testing
- API-triggered AI review
- Structured review panel with summary, score, issues, and suggestions
- Clear, retry, and loading states

## Run

Start backend first at `http://localhost:8001`, then:

```bash
cd frontend/code-review-ai
npm install
npm run dev
```

## Tech

- React
- Vite
- Monaco Editor
- Axios
