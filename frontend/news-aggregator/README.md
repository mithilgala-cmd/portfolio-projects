# News Aggregator Frontend

React UI for the News Aggregator API.

## Features

- Top headlines on load
- Debounced search
- Loading, error, and empty states
- Card-based article list

## Run

Start backend first at `http://localhost:8000`, then:

```bash
cd frontend/news-aggregator
npm install
npm run dev
```

## Tech

- React
- Vite
- lucide-react
