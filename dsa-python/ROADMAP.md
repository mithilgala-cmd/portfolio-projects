# DSA Roadmap (12 Weeks)

This roadmap is designed for placement preparation.

## Weeks 1-2: Foundations

- Arrays
- Hashing
- Two pointers
- Sliding window

Target:

- 20-25 problems
- Strong O(n) optimization habits

## Weeks 3-4: Core Structures

- Stack
- Linked list
- Binary search
- Intervals

Target:

- 20 problems
- Fast pattern identification in interviews

## Weeks 5-6: Trees and Heaps

- Trees (DFS and BFS)
- Heap / priority queue
- Trie basics

Target:

- 18-22 problems
- Confident recursion and tree traversal

## Weeks 7-8: Graphs and Backtracking

- Graph traversal
- Topological sort
- Backtracking templates

Target:

- 18-22 problems
- Clean recursion and pruning logic

## Weeks 9-10: Dynamic Programming

- 1D DP
- 2D DP
- Knapsack style transitions

Target:

- 20 problems
- Strong state definition and transitions

## Weeks 11-12: Mixed Revision + Mock Rounds

- Mixed sets across all patterns
- Timed contests
- Revision of weak areas

Target:

- 25+ revision problems
- Interview-speed confidence

## Weekly Routine

- 5 days solving
- 1 day revision
- 1 day mock interview and retrospective
