# DSA Projects

This directory is reserved for DSA-adjacent mini projects that strengthen placement discussions.

## Suggested Projects

1. Problem Tracker CLI
   - Track solved problems by pattern and difficulty.
   - Export weekly progress summary.

2. Complexity Visualizer
   - Compare runtime growth of O(n), O(n log n), O(n^2).
   - Useful for interview explanation practice.

3. Pattern Recommender
   - Given a problem statement, suggest likely DSA patterns.
   - Rule-based first, then improve gradually.

4. Test Case Generator
   - Generate random edge-heavy inputs for array/string problems.

Start with one project and keep it small, testable, and documented.
