# Problem Tracker (Planned)

A simple CLI project to log solved DSA problems.

## MVP

- Add solved problem entry
- List by pattern
- List by difficulty
- Weekly summary output

## Suggested Stack

- Python
- `argparse` for CLI
- JSON file or SQLite for storage

## Why this helps placements

- Shows consistency and discipline
- Demonstrates practical Python engineering beyond pure problem solving
- Provides measurable prep progress
